# 传感器胶水效果和气密性测试

**测试目的：**

本测试用于验证3M和乐泰胶水的密封性，同时测试传感器整体的密封性。

**测试产品：**

LT-200传感器

# 3M-3581UV胶

## 打胶

测试时，使用新的外壳和金刚石。

主观感受：3M-3581呈乳白色，黏稠度较低

固化方法：使用1000mw/cm²的UV灯照射20s，在80℃恒温箱烘50分钟

打胶位置：金刚石片、光源板支架、导光柱

## 气密性测试

### 2.1 测试方法

使用气密性检测仪，对传感器内部充压，停止充压后，观察指针示数。

气密性检测仪如下图所示，其量程为300mmHg，等效压强约为0.4bar。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqrebpexYo8nak/img/51747e31-d450-4779-9327-fc896dac0c0c.png "气密性检测仪（300mmHg量程）")

测试时，使用如下待测传感器，其中左侧有一个通气孔，将此通气孔与气密性检测仪连接，并保证连接处气密性良好。对传感器内部充气，气压大小控制在220mmHg~300mmHg（等效水压约3m），充气结束后进行保压，观察仪器仪表指针是否存在较大差异，重复测试至少3次。

# 测试结论：

**本测试仍有多处不完善之处，待后续进一步测试**，现先给出阶段性结论：

1.  3M和乐泰均推荐了多款胶水，同时也强调，所推荐胶水中，其中一种若能满足多场景需求，可优先选择使用，经测试，UV胶目前能满足光源板、导光柱、金刚石的粘接，主要排除了UV胶的高温挥发影响。
    
2.  推荐乐泰3493UV胶，性状透明，密封性好，黏度低，保存方便；不推荐3M胶水：乳白色影响外观，密封性还有待验证，保存和固化条件苛刻。
    
3.  不推荐在导光柱上使用3M的5520，会导致光强衰减。
    
4.  传感器存在多处漏气：导光柱、金刚石片、同轴线插座、供电插座，使用乐泰3493后，导光柱、金刚石片无漏气。
    

**待完善之处：**

1.  导光柱处重新点胶，尽量使胶水平铺面积大一点
    
2.  重新安装金刚石，点胶更加均匀一些
    
3.  拧紧同轴线插座（考虑到后期要替换，此项可延后）
    
4.  胶水效果因点胶工艺而异，需多次测试。
